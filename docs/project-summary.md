# Project summary

## Назначение

BuildRent — курсовой fullstack-проект для аренды строительного оборудования. Сервис закрывает полный цикл: от публичного каталога и расчёта аренды до клиентского кабинета, управления заявками и административной отчётности.

## Что реализовано

- публичный каталог с категориями, поиском, фильтрами, сортировкой и карточкой оборудования;
- регистрация и вход с JWT-авторизацией;
- защищённые маршруты для клиента и отдельная роль администратора;
- оформление аренды с расчётом стоимости, доставкой и созданием заявки;
- личный кабинет клиента: избранное, история заявок, профиль, отчёты;
- админ-панель для работы с заявками, оборудованием, категориями, пользователями, отзывами и отчётами;
- генерация документов в форматах `PDF` и `DOCX`;
- воспроизводимая demo-база данных с `543` записями.

## Архитектура

- frontend: `React + TypeScript + Vite + Redux Toolkit + React Router + Tailwind CSS`
- backend: `Node.js + Express + TypeScript + Prisma + PostgreSQL`
- авторизация: `JWT Bearer`
- документы: `pdfkit`, `docx`

Проект организован как monorepo с двумя workspace:

- `client` — интерфейс пользователя и администратора;
- `server` — API, бизнес-логика, Prisma schema, seed и backup.

## Демо-покрытие

На финальном прогоне проверены:

- публичные маршруты `/`, `/catalog`, `/equipment/:slug`, `/login`, `/register`, `/404`;
- редиректы с защищённых маршрутов для гостя на `/login`;
- клиентский доступ к `/favorites`, `/orders`, `/orders/:id`, `/profile`, `/reports`, `/checkout`;
- блокировка доступа клиента к `/admin` с возвратом на `/`;
- загрузка админ-страниц `/admin`, `/admin/orders`, `/admin/equipment`, `/admin/categories`, `/admin/users`, `/admin/reviews`, `/admin/reports`;
- адаптивные viewport-проверки ключевых страниц без горизонтального overflow.

## Финальные технические примечания

- React Router переведён на future flags, чтобы убрать предупреждения перед v7.
- CORS настроен так, чтобы локально работали и `localhost`, и `127.0.0.1` на одном порту.
- Seed очищает временные и дублирующие demo-записи перед повторным созданием эталонного набора данных.
- README и материалы `docs/` приведены к финальному состоянию для сдачи и демонстрации.
