# BuildRent

BuildRent — курсовой fullstack-проект онлайн-платформы аренды строительного оборудования. Сервис объединяет публичный каталог техники, оформление аренды, личный кабинет клиента и административную панель для управления оборудованием, заявками, пользователями, отзывами и отчётами.

Проект реализован как monorepo с frontend на `React + TypeScript + Vite` и backend на `Node.js + Express + Prisma + PostgreSQL`. Основная цель системы — показать полный цикл аренды: от выбора оборудования и расчёта стоимости до сопровождения заказа и внутренней операционной работы администратора.
